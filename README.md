# Лендинг «23 года вместе»

Адаптивная HTML/CSS-верстка по обновленному макету Figma. Тексты, карточки,
расписание, кнопки, контакты и форма собраны отдельными HTML-элементами.
Изображениями остаются только фотографии и декоративные растровые объекты,
извлеченные из исходного `.fig`.

Кнопка «Регистрация» открывает модальную форму с проверкой обязательных полей и
экраном подтверждения. Для реальной отправки заявок потребуется подключить API
или CRM.

## Запуск

Откройте `index.html` напрямую или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

После этого откройте `http://localhost:8000`.

Для работы формы запускайте защищённый сервер приложения:

```bash
python3 server.py
```

Он обслуживает статику на `http://localhost:8433` и принимает заявки по
`POST /api/registration`. Обработчик проверяет origin, тип и размер запроса,
валидирует допустимые поля, использует honeypot и ограничивает частоту заявок.
После проверки заявка передаётся существующему серверному обработчику события.
Для боевого использования сайт необходимо публиковать по HTTPS.
