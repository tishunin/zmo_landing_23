# Лендинг «23 года вместе»

Адаптивная HTML/CSS-верстка по обновленному макету Figma. Тексты, карточки,
расписание, кнопки, контакты и форма собраны отдельными HTML-элементами.
Изображениями остаются только фотографии и декоративные растровые объекты,
извлеченные из исходного `.fig`.

Кнопка «Регистрация» открывает модальную форму с проверкой обязательных полей,
отправкой заявки на почту и экраном подтверждения.

## Запуск

Откройте `index.html` напрямую или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

После этого откройте `http://localhost:8000`.

Форма отправляет заявки в `POST /api/feedback.php`. PHP-обработчик проверяет
origin, тип и размер запроса, валидирует допустимые поля, отправляет JSON в
Ingeni и формирует резервное текстовое письмо. Также используются honeypot и
ограничение частоты заявок. Получатель письма задаётся константой `MAIL_TO`,
а адрес интеграции — константой `INGENI_ENDPOINT` в начале обработчика.

Для работы формы серверу требуются PHP 8.1+, настроенный почтовый транспорт и
веб-сервер, исполняющий только `api/feedback.php`. Для боевого использования
сайт необходимо публиковать по HTTPS.
